## 相互了解100问：来源与复制许可

- 来源：[デジタル教科書：コピペOK！自己紹介に最適な100の質問](https://fucchan-blog.com/100questions/2517/)，原页标示日期为 2023-03-16。
- 题单位置：原页 `100の質問` 有序列表，从第1项姓名到第100项结束语，实计100个编号条目。不是从其它问卷补足，也不要求100个语义互异的问题。
- 许可证据：页面标题明确写有「コピペOK」，导语为「コピペして使える100の質問を用意しました。」。这是原站的复制使用许可，不是 CC0、CC BY、公共领域声明，也不据此推定整站所有内容可任意再许可。`license_url` 指向这段许可所在的原页。
- 署名采用页面实际展示的站名「デジタル教科書」及域名；所核对原页未单列个人作者，不凭域名猜个人姓名。
- 第28、37题原文完全相同，均问喜欢的季节：保持两个位置和相同译文，不能去重后自编一题。
- 第48题原文列为「年上？同い年？年上？」；第三项重复了年长，可能是笔误，但未获作者确认。译文照录并附简短译注，不擅自改成「年下」。
- 第85题原文的「とこと」按句意理解为希望改善的地方；不改变提问目标。第8题的足部尺寸用中文常用的鞋码表达；第11、12题的「部活」译作社团，第13题的「習い事」译作兴趣班或才艺学习。第61题保留「アーティスト」可指艺术家或音乐人的范围。
- 名词式题目补成自然的中文问句；原来的二选一措辞仍是自由文本提示，不增设选项、评分、必答或人格诊断。没有把问卷改写为角色创建表。

## 作答与数据约定

两套均用于自愿交流，每题是开放文本，无分值、答案键、选项数组或强制作答设置。隐私、敏感、不适用或让人不舒服的题都可跳过，也可回答「不适用／不愿回答」，不必解释原因。没有相关体验即可如实说明。AI 不必编造生日、年龄、身高、血型、家庭、身体体验或私人经历，也不必扮演虚构角色才能参与。

数据只包含约定的 `topic_id,title,description,author,source_url,license,license_url,adaptation_note,questions`；每个 question 只有 `id,text,source_ref`。ID 采用 `题包ID_三位原题号`，如 `getting_to_know_100_001`，同包顺序固定且全体135个 ID 唯一。`source_ref` 是源页区块标题加原题号，通过该题包的 `source_url` 查找；它不是虚构的网页锚点。后续勘误应保留 ID 和位置。

原文对照和较长证据只放在此文档，运行时题库不重复保存外文全文。没有变更后端、前端、根 MCP 或任何公共 guide/schema；这里的跳过说明是内容约定，不声称实现或验证了运行时跳题交互。
